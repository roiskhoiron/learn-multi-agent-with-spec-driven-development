# 🍳 Mini ChefGenie: Spec-Driven Orchestration yang Sat-Set!

Jujurly, ini adalah project yang *literally* game changer buat workflow kita. Kita nggak lagi *manual coding* yang *draining* banget, tapi kita mainnya di level *strategic orchestration* pake **Spec-Driven Development**.

---

## 💅 The Jaksel Corporate Way (Explain Like I'm at SCBD)

Jadi gini, *basically* kita punya dua *resource* yang *highly competent* di tim kita:

1.  **Robot Penulis (SpecAwareCoder)**: Dia ini *key person* buat *execution*. Lo kasih dia *brief* (YAML Spec), dia bakal langsung *deliver* kode Python yang *robust* dan *scalable*. Dia *literally* gercep banget, *no cap*.
2.  **Robot Pemeriksa (SpecValidator)**: Dia ini perannya kayak *QA Lead* yang *picky* abis. Tugasnya buat *double check* apakah output si Coder udah *aligned* sama *KPI* (Test Cases) yang kita set di awal. 

**How's the workflow?**
Kita kasih mereka **The Blueprint (Spec)**. Si Coder bikin kodenya, terus si Validator bakal *review* secara *meticulous*. Kalo kodenya belum *perfect*, mereka bakal *feedback-loop* terus sampe kodenya **"VALID"**. Pokoknya *seamless* banget lah, *end-to-end* udah di-handle sama mereka. *Value creation*-nya dapet banget! 🚀

## 🏢 Business Unit Structure (Folder)

- `specs/`: Ini *knowledge base* kita, isinya *requirement* yang udah *final*.
- `agents/collaborative_agents.py`: Ini *headcount* robot-robot kita yang *high-performing*.
- `generated/`: Ini *output* yang udah *approved* dan siap di-*deploy*.
- `main_spec_driven.py`: Ini *button* buat *trigger* diskusi tim robotnya. *Point of entry*, gitu loh.

## 🛠️ How to Sync (Running the Project)

1. **Activate the Environment:**
   *Make sure* lo udah di dalem `venv`, biar nggak *clash* sama *library* lain.
   ```bash
   source venv/bin/activate
   ```

2. **Onboarding Dependencies:**
   Kita perlu *install* beberapa *tools* biar robotnya bisa *working properly*.
   ```bash
   pip install -r chefgenie-autogen/requirements.txt
   ```

3. **Execute the Vision!**
   Langsung aja *hit* script-nya buat liat *magic*-nya.
   ```bash
   python chefgenie-autogen/main_spec_driven.py
   ```
